# GPU requirements — extends requirements.txt by swapping torch for CUDA wheels.
#
# Install order:
#   1. Uninstall CPU torch first (if already installed):
#        pip uninstall torch torchaudio -y
#
#   2. Install CUDA-enabled torch (pick the line that matches your CUDA version):
#        # CUDA 12.1  (RTX 30xx / 40xx, most modern GPUs)
#        pip install torch==2.3.0+cu121 torchaudio==2.3.0+cu121 --index-url https://download.pytorch.org/whl/cu121
#
#        # CUDA 11.8  (older GPUs)
#        pip install torch==2.3.0+cu118 torchaudio==2.3.0+cu118 --index-url https://download.pytorch.org/whl/cu118
#
#   3. Install the rest of the project requirements:
#        pip install -r requirements-gpu.txt
#
# Note: faster-whisper uses CTranslate2 for inference, NOT torch directly.
# CTranslate2 ships a CUDA-enabled wheel automatically when installed on a
# machine with a CUDA driver. No separate GPU build step is needed.

# Everything else is exactly requirements.txt (one list, so the two machines cannot drift apart):
-r requirements.txt
